# Kalanjali

A paintings gallery and art-supply store inspired by Telugu tradition. Every painting comes with a short story and a hidden meaning. The site also has live painting sessions, a colour-mixing studio, a shopping cart and a journal.

The project has two separate parts: a **frontend** (what visitors see) and a **backend** (an API that serves the data).

## Folder structure

```
Paintings/
├── frontend/          Static website (HTML, CSS, JavaScript)
│   ├── index.html
│   ├── style.css
│   ├── script.js      <- API_URL at the top points to the backend
│   ├── images/        Paintings and store pictures
│   └── package.json
└── backend/           Express API
    ├── server.js
    ├── data/          paintings.json, products.json, blog.json, sessions.json
    ├── tools/         Scripts that generate the sample artwork
    ├── .env.example   Names of the settings the backend will need
    └── package.json
```

## Run it locally

You need [Node.js](https://nodejs.org) installed. Use two terminals.

**1. Backend** (API on port 3100)

```
cd backend
npm install
npm start
```

**2. Frontend** (website on port 5500)

```
cd frontend
npm install
npm start
```

Then open **http://localhost:5500** in your browser.

## Important: API_URL

At the top of `frontend/script.js` there is a line:

```js
const API_URL = "http://localhost:3100";
```

`API_URL` must point to the backend. Keep it as above for local work, and change it to your live backend address when you deploy.

## Settings and secrets

Copy `backend/.env.example` to `backend/.env` and fill in your own values when a feature needs them. Never commit the real `.env` file. It is listed in `.gitignore`.

## Notes

- The paintings, blog posts, sessions and products are demo data.
- The sample artwork is generated by the scripts in `backend/tools/`. Running `node tools/generate-art.js` overwrites `backend/data/paintings.json`, so don't run it after adding real paintings.
